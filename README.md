# TargetPath

TargetPath is a web-based system for exploring the relationship between diseases, target proteins, compounds, and bioactivity data.

The system integrates data from:
- **Open Targets** for disease–target associations
- **ChEMBL** for compounds and bioactivity data
- **Greedy Best-First Search (GBFS)** for priority-based exploration

The exploration flow is:

**Disease → Target Protein → Compound → Bioactivity**

TargetPath is designed to help users systematically explore potential candidates and their associated bioactivity data. The results are intended for further exploration and are not clinical recommendations or evidence of therapeutic effectiveness.
